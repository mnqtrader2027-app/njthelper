Step-by-Step: Think of OIF Like a Note to NinjaTrader

      

        

          
1. Build the instruction

          
Choose BUY or SELL, quantity, order type, and prices. The instrument stays MNQ so the page cannot accidentally create an ES, NQ, stock, or crypto OIF.

        

        

          
2. Read the preview

          
The line uses semicolons like dividers in a form. For example, PLACE;Sim101;MNQ 12-26;BUY;1;MARKET...

        

        

          
3. Export the text file

          
The browser downloads a file whose name starts with oif. Your browser cannot safely write directly into NinjaTrader's watched folder.

        

        

          
4. Move it to NinjaTrader

          
NinjaTrader watches its incoming folder. NinjaTrader recommends unique OIF filenames and recommends moving or directly writing a finished file rather than copying a file that is still being written.

        

        

          
5. Watch order status

          
A separate local server can watch NinjaTrader's outgoing files and expose status to this browser page. This static page intentionally does not read your Windows filesystem.

        

        

          
6. Practice first

          
Use Sim101 while learning. A correct OIF placed into the live workflow can create a real futures order.
